# Gewählte Technologie
Chart.js 
Chart.js ist eine JavaScript-Bibliothek zur Darstellung von Diagrammen im Browser
z.B. Balken, Linien oder Kreisdiagramme.

# Begründung der Auswahl
Ich habe mich für Chart.js entschieden, weil die Bibliothek übersichtlich aufgebaut ist, Resultate schnell sichtbar sind, sie sich gut für sowas eignet, sie ohne komplexes Setup verwendet werden kann
Zudem ist Chart.js eine realistische Technologie, die auch in realen Projekten eingesetzt wird.

# Erste Einarbeitung

Die Bibliothek wird über ein CDN eingebunden und benötigt lediglich ein
HTML-Canvas-Element sowie eine JavaScript-Konfiguration.
